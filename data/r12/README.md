# R12 open data for Supabase

Public Swiss open data (ElCom tariffs, BFS postcodes/municipalities, energiefranken programmes, BFE/ich-tanke-strom charging tariffs, TCS tax examples, KBOB factors).
Loaded into the team Supabase by the n8n workflow "Import – R12 tables into Supabase" (folder Test Claude). Table definitions: `01_create_tables.sql`.
Not served by the website (only `public/` is deployed).
